# Importación de Biblias

Descarga los paquetes USFM oficiales de eBible.org y ejecútalos con `import_usfm.py`.

- RV1909: `https://ebible.org/Scriptures/spaRV1909_usfm.zip`
- WEB: `https://ebible.org/Scriptures/engwebp_usfm.zip`

El repositorio incluye unos versículos demostrativos para que el proyecto abra sin pasos adicionales. Antes de distribuir la app, reemplaza esos archivos por los corpus completos generados con el importador.
